# Free Swing — changelog

Newest first. Each release's notes come from `CHANGELOG.md` at the time it was published.

## Free Swing 2.5.2

- `/swing reset` with an unknown bar name now shows the help instead of resetting every bar.
- Cleanup: unused files and old settings removed from the package.
- Fresh installs: the default positions are now measured from the centre of the screen and fit a 1920×1080 screen (they were set for a very wide screen and could end up off screen).
